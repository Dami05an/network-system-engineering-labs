# 01 – CCNA Labs & Network Projects

## About This Section

This section contains my practical work and hands-on labs related to the **Cisco CCNA 200-301 certification**.

The main objective is to develop and strengthen my networking skills by building, configuring, testing, and troubleshooting different network infrastructures using **Cisco Packet Tracer**.

Each project focuses on specific CCNA topics and concepts, allowing me to put theoretical knowledge into practice and gain practical experience with Cisco networking devices.

As I progress through my CCNA studies, I will regularly add new labs and projects to this section.

## Project Structure

Each project will follow a standardized structure to make it easy to understand, reproduce, and modify.

The following files will be included whenever relevant:

| File | Description |
|---|---|
| `01_PROJECT_OVERVIEW.pdf` | Project objectives, professional context, and skills covered. |
| `02_NETWORK_TOPOLOGY.png` | Screenshot of the complete network topology, including devices and connections. |
| `03_CISCO_CONFIGURATION.txt` | Cisco configuration commands used on routers and switches. |
| `04_TECHNICAL_DOCUMENTATION.pdf` | Technical documentation explaining how the network works and the technical decisions made. |
| `05_TESTS_AND_VALIDATION.pdf` | Validation and troubleshooting tests, including Ping, Traceroute, `show vlan`, `show interfaces trunk`, and other relevant commands. |
| `06_PACKET_TRACER_PROJECT.pkt` | Original Cisco Packet Tracer project file, available for download and modification. |
| `07_ISSUES_AND_SOLUTIONS.pdf` | Problems encountered during the project, their causes, and the solutions implemented. |

## Passwords & Lab Security Notice

**Important:** For educational and practical purposes, passwords used in these Packet Tracer labs may be documented in plain text.

This is intentional and allows anyone downloading the `.pkt` file to access the configurations, reproduce the lab, modify the infrastructure, or experiment with different settings.

This practice is strictly limited to educational lab environments.

**In a real production environment, passwords and other sensitive credentials must never be stored or documented in plain text.** Appropriate security practices, access controls, and credential management solutions must always be implemented.

## Learning Objectives

Through these projects, I aim to develop practical skills in:

- Network configuration and administration.
- Cisco IOS command-line interface (CLI).
- VLANs and Inter-VLAN routing.
- Trunking and EtherChannel.
- Spanning Tree Protocol (STP).
- IPv4 addressing and subnetting.
- Static and dynamic routing.
- DHCP and DNS configuration.
- Network security and access control.
- Network troubleshooting and validation.

*This list will evolve as I progress through the CCNA curriculum.*

## My Approach

Each project follows a practical learning process:

1. **Understand:** Study the networking concepts involved.
2. **Design:** Create the network topology.
3. **Configure:** Implement the necessary configurations.
4. **Test:** Verify connectivity and network functionality.
5. **Troubleshoot:** Identify and resolve configuration issues.
6. **Document:** Record the configurations, technical decisions, tests, and solutions.
7. **Share:** Upload the completed project and its Packet Tracer file to GitHub.
